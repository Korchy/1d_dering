# 1D Dering

Blender add-on.

Removes edges by checker deselecting, starting from single selected edge.

***
This repository is archived, all the add-on functional is transferred to the 1d_deloop https://github.com/Korchy/1d_deloop add-on!
***

Add-on functionality
-
Select single face. When executing all similar checker selected edges will be dissolved.
